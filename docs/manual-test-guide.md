# 수동 테스트 가이드

## auto-capture

### 기본 동작
- [ ] 앱 실행 후 "시작" 클릭 → 영역 선택 오버레이 표시 확인
- [ ] 드래그로 영역 선택 → 초록 번호 배지(1) 표시 확인
- [ ] 추가 드래그 → 번호 배지(2) 추가 확인
- [ ] Enter 키 → 오버레이 닫히고 모니터링 시작 확인
- [ ] 상태 레이블 "모니터링 중... (2개 영역)" 표시 확인
- [ ] ESC 키 → 오버레이 전체 취소 확인

### 감지 동작
- [ ] 감지 영역 내 화면 변화 발생 시 → 소리 없이 커서 이동 확인
- [ ] 감지 후 상태 "일시정지" 전환 확인
- [ ] "재시작" 클릭 → 모니터링 재개 확인

## auto-clicker

### 클릭 시퀀스
- [ ] 클릭 포인트 등록 후 실행 → 순서대로 클릭 확인
- [ ] 마지막 클릭 완료 시 소리 1회 재생 확인
- [ ] 중단(Stop) 시 소리 없음 확인

### auto-capture 연동
- [ ] auto-capture에서 감지 → auto-clicker IPC 수신 → 즉시 클릭 후 시퀀스 실행 확인
- [ ] 클릭 시퀀스 완료 시 소리 1회 재생 확인 (감지 시점에 소리 없음)
