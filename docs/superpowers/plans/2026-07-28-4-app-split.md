# autotools 4-앱 분리 + 공유 패키지 추출 구현 계획

> **For agentic workers:** 이 계획은 오케스트레이터가 각 Task를 `.omc/tasks/<task>.md` 워커 작업지시서로 변환해 cmux 워커(surface:2=clicker 계열, surface:3=capture 계열)에 발주한다. 각 Task는 독립적으로 pytest/스모크 게이트를 통과해야 다음으로 넘어간다. 체크박스(`- [ ]`)로 진행을 추적한다.

**Goal:** 2개 앱(auto-capture, auto-clicker)을 uv 워크스페이스 기반 공유 패키지(`autotools_shared`) + 4개 독립 앱(motion-capture, color-capture, motion-clicker, color-clicker)으로 재구조화한다.

**Architecture:** uv 워크스페이스 모노레포. 루트 아래 `shared/`(설치 가능한 로컬 패키지)와 `apps/`(4개 앱). 각 앱은 `autotools_shared`를 경로 의존성으로 참조하고, 2쌍의 IPC 소켓(포트 54321/54322)으로 통신한다.

**Tech Stack:** Python ≥3.14, PySide6, mss, numpy, pynput, uv, PyInstaller.

## Global Constraints

- 구현은 워커에 위임. 오케스트레이터는 `shared/`·`apps/`·`docs/`·워크스페이스 루트 파일만 필요 시 직접 편집 가능하나, `auto-capture/`·`auto-clicker/` 소스는 반드시 워커에 위임(PreToolUse 훅이 직접 편집 차단).
- Python floor: `requires-python = ">=3.14"` (모든 pyproject 동일).
- 앱 exe는 앱당 1개, 총 4개. 각 앱 독립 실행/빌드 가능.
- IPC 짝: motion-capture↔motion-clicker=**포트 54321**, color-capture↔color-clicker=**포트 54322**.
- IPC 메시지 포맷 유지: `{"event": "motion"|"color_match", "x": int, "y": int}` + `\n` 구분.
- macOS에서 pynput 문자키 Listener는 크래시 위험 → 전역훅은 함수키/조합키만, ESC 리스너는 `sys.platform == "win32"` 분기에서만.
- 각 마이그레이션 단계는 앞 단계 완료가 선행 조건. 단계 종료 시 관련 pytest 전부 통과 + 각 앱 `import main` 스모크 필수.
- 리팩터링은 **동작 보존**(기능 변경 없음). 기존 미해결 버그는 이 계획 범위 밖(별도 작업).

## 검증 명령 규약

- 워크스페이스 전체 테스트: `uv run pytest`
- 특정 패키지 테스트: `uv run --package <name> pytest` 또는 해당 디렉터리에서 `uv run pytest`
- 파이썬 인터프리터는 워크스페이스 `.venv` 사용. 절대 경로가 필요하면 `/Users/yi-gwangho/Projects/ticketure/.venv/bin/python`.
- 앱을 직접 GUI 실행하지 않는다(워커). 런타임/스크린샷 검증은 오케스트레이터가 macOS에서, Windows 전용 항목은 사용자가 확인.

- [ ] **Step 2: `base.py`로 공통 요소 추출**

`point_picker.py`의 `_EscFilter`/`_EscRelay`와 `color_picker.py`의 `_EscFilter`/`_EscRelay`는 동일 패턴이다. 이를 `base.py`로 이동:
```python
import sys
from PySide6.QtCore import Qt, QObject, QEvent, Signal


class EscFilter(QObject):
    """Qt 레벨 ESC 필터 (macOS/Linux)."""
    def __init__(self, callback):
        super().__init__()
        self._callback = callback

    def eventFilter(self, obj, event):
        if event.type() == QEvent.Type.KeyPress and event.key() == Qt.Key.Key_Escape:
            self._callback()
            return True
        return False


class EscRelay(QObject):
    """pynput 스레드 → Qt 메인 스레드 안전 브릿지 (Windows 전용)."""
    _sig = Signal()
    def __init__(self, callback):
        super().__init__()
        self._sig.connect(callback, Qt.ConnectionType.QueuedConnection)
    def notify(self):
        self._sig.emit()


def install_windows_esc_listener(callback):
    """Windows에서만 pynput 전역 ESC 리스너를 설치하고 (relay, listener)를 반환. 그 외엔 (None, None)."""
    if sys.platform != "win32":
        return None, None
    try:
        from pynput import keyboard as _kb
        relay = EscRelay(callback)

        def _on_press(key):
            if key == _kb.Key.esc:
                relay.notify()
                return False

        listener = _kb.Listener(on_press=_on_press)
        listener.start()
        return relay, listener
    except Exception:
        return None, None
```

class HotkeyRelay(QObject):
