### 버전명 RGB Catch Catch

현재 프로그램의 문제점.
오토 캡쳐의 문제점은 픽셀 변화를 알아채기 때문에 새로고침되는 화면에서는 사용하지 못 한다. 그래서 내가 몇 가지 아이디어를 냈다.

RGB 값을 따올 수 있도록 하자.
오토 캡쳐에 탭을 추가해서 컬러 캐쳐로 만든다.
rgb 값을 기억하고 있다가  변경된 지점이 있다면 오토 클리커에 포인트 전달하는 로직은 동일하다.
오토 클리커는 특정 영역을 연속으로 누를 수 있어야하며 클릭과 클릭 사이에 밀리세컨드 범위 지정 할 수 있게 한다. 너무 동일한 간격으로 클릭하는 것을 방지하기 위함이다. 인간이 연속으로 버튼 클릭 시 100ms 같이 동일한 간격으로 누르는 것을 불가능하다. 사람은 보통 연속으로 누를 때 어느 정도의 텀이 생기는지 알고리즘이 있다면 적용해라.

## 모드
새로 적용 되는 모드에서는 기존 플로우와 겹치면 안 되기 때문에 탭으로 나눠서 모드를 관리한다. 동일한 로직이 있다면 재사용하게 한다.

### 오토 캡쳐
- 기존 모드 : 오토캡쳐
- 새로운 모드 : 컬러캡쳐

### 오토 클리커
- 기존 모드 : 오토 클리커
- 새로운 모드 : 컬러 클리커


## 플로우
플로우는 아래와 같다.

기존 플로우
1. 오토 캡쳐와 오토 클리커 연결
2. 오토 클리커 클릭 영역 순서대로 지정
3. 오토 캡쳐 감시 할 영역 지정
4. 오토 캡쳐 영역 내에 변화하는 부분이 생기면 오토 클리커에 좌표 전송
5. 2)의 지정된 영역 순차대로 클릭

추가 되는 모드에서는
1. 오토 캡쳐와 오토 클리커 연결
2. 오토 캡쳐 : 감지할 RGB 지정
3. 오토 캡쳐 : 감시 영역을 지정한다.
4. 오토 클리커 : 클릭 영역 순서대로 지정
5. 오토 클리커 : 연속 클릭의 밀리 세컨드 범위를 지정한다.
6. 오토 클리커 : 연속 클릭 할 영역을 지정한다.
7. 오토 클리커 : 오토 캡쳐 감지 시 수행할 클릭 영역 순서대로 지정한다.
8. 오토 캡쳐 : RGB 영역 포착 후 오토 클리커에 좌표 전송
9. 오토 클리커에 : 4)의 지정된 영역 순차대로 클릭


## 추가 기능
### 오토 캡쳐
- 특정 화면 영역의 RGB를 뽑아서 기억하는 기능이 필요하다.
- 화면 영역 지정후 감시할 때 내가 지정한 RGB 값이 발견되는지 감시 후 감지 된다면 클리커에 전달한다.
### 오토 클리커
- 연속 클릭 할 영역 지정을 추가한다. 연속 클릭 시, 클릭 간의 시간 범위를 밀리세컨드 단위로 지정한다. Ex) 10 ms ~ 100 ms
- 연속 클릭은 오토 캡쳐가 RGB값 감시 성공하는 순간 정지하며, 변화된 포인트를 클릭하고, 기존 오토 클리커와 마찬가지로 순서대로 클릭할 영역들을 클릭한다.
